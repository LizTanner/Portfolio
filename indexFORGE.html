Confluence Forge App Demo

With Confluence Analytics only available to Premium and Enterprise Atlassian customers, Free and Standard users are very limited as to what Confluence data analytics they can view, extract, and report. Built from scratch, this Confluence Forge app uses a GET request on a Confluence CLoud REST API CQL endpoint to fetch data analytics and display the results in a Dynamic Table UI kit component. This app enables Atlassian Free-tier and Standard-tier users to extract Confluence data for analysis and reports without requiring a Premium/Enterprise license.
