Forge App Demonstrations

Confluence Forge App Demo

Built from scratch, this Confluence Forge app uses a GET request on a Confluence REST API CQL endpoint to fetch data analytics and display the results in a Dynamic Table component. This app enables Atlassian Free-tier and Standard-tier users to extract Confluence data analytics without needing to purchase an expensive Premium/Enterprise license for Confluence Analytics.

Jira Forge App Demo

This build is a simplified version of the more complex "Jira Project Stats App" from Atlassian's Forge Examples Bitbucket repo. The original app used nested actions to display backlog and board data in pie chart visualizations and export data from each board in JSONs. Attendees were shown how to recognize what code blocks expressed specific components and actions. This enabled attendees to identify the code to remove nested items and the export action to create a simplified app displaying data from only one board in a pie chart visualization. This part of the workshop showed non-coders and non-developer attendees how to create apps who lacked coding and app development skills.
