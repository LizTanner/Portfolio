Power Automate Tutorials

The video tutorials using Power Automate are in a three part playlist showcasing how a simple invoice processing system can be developed using: (1) Power Automate Desktop flows and Microsoft desktop apps only, (2) Power Automate Cloud flows and Microsoft cloud apps only, and (3) a hybrid flow using Power Automate Premium connectors and features. Video tutorials showing how to create the components used in the different flows are also included in this playlist.

Create an invoice processing system with PAD

In this video tutorial, I created an invoice processing system using a Power Automate Desktop (PAD) flow. The challenge for creating this flow was using only Microsoft desktop apps and tools/features available on Windows 11 Pro. No cloud or Premium features were used. This tutorial shows how Word, Excel, and PDFs can be used in a desktop flow to process invoices for SMBs and small teams.
